# Cama Elástica Média (2,44m)

A Cama Elástica Média de 2,44 metros é o tamanho mais popular para festas. Com espaço suficiente para 2 a 3 crianças pularem simultaneamente, ela é a escolha certa para a maioria dos eventos.

## Características

- Diâmetro de 2,44 metros
- Estrutura em aço galvanizado reforçado
- Molas de alta resistência e durabilidade
- Rede de proteção completa e resistente
- Capacidade para 2 a 3 pessoas

## Ideal para

- Festas de aniversário
- Eventos escolares
- Condomínios e áreas de lazer
- Eventos corporativos com crianças

## Segurança

Rede de proteção completa com zíper de segurança. Molas cobertas por capa protetora. Base antiderrapante. Inspeção técnica antes de cada locação.
